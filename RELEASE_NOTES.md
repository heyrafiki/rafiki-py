# 0.1.0b1 source preview

The first source preview covers the complete published version 1 contract: Practitioner discovery, Bookings, Sessions, Benefits, Claims, remittance and Webhooks.

The package includes sync and async clients, typed models, caller-owned idempotency keys, bounded retries and the shared API error envelope. Examples use synthetic data.

This version has not been published to PyPI. A package release requires protected repository settings, a reviewed GitHub release and provenance-backed artifacts from the release workflow.
