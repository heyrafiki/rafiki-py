# 0.1.0b1

This version covers the complete published version 1 contract: Practitioner discovery, Bookings, Sessions, Benefits, Claims, remittance and Webhooks.

The package includes sync and async clients, typed models, caller-owned idempotency keys, bounded retries and the shared API error envelope. Examples use synthetic data.

The verified source-install path is available from this repository. Releases
are produced from reviewed GitHub tags with provenance-backed artifacts.
